# 04 擬似課金とオファーエンジン

## 1. 原則
1. **実決済は一切行わない。** 決済 SDK（Play Billing 等）への依存を持たない。CI で依存グラフを検査する。
2. **ブランドを模倣しない。** Google / Google Play / カード会社 / 決済事業者のロゴ・名称・固有配色・固有文言（例: 注文番号の実在フォーマット）を使わない。決済シートは「汎用的な決済 UI らしさ」に留める。
3. **配布しない。** 個人のサイドロード専用。ストア公開は不可。
4. 「課金してる感」は **選択の重さ（価格表示）× 待ち（処理中）× 完了演出 × 即時報酬 × 社会的証明** で作る。

## 2. 通貨と価格体系
- 表示通貨は円（`¥`）。価格はあえて量産型の端数（¥160 / ¥610 / ¥1,220 / ¥3,060 / ¥6,100 / ¥12,000）。
- ジェム単価は SKU ごとに異なる（換算不明化）。
- 「初回購入 2 倍」フラグは SKU ごとに 1 回。

### ジェム SKU
| SKU | 価格 | ジェム | ボーナス |
| --- | --- | --- | --- |
| gems_s | ¥160 | 100 | +0 |
| gems_m | ¥610 | 500 | +50 |
| gems_l | ¥1,220 | 1,000 | +150 |
| gems_xl | ¥3,060 | 2,500 | +500 |
| gems_xxl | ¥6,100 | 5,000 | +1,200 |
| gems_max | ¥12,000 | 10,000 | +3,000 |

### パック類（`offers.json`、価格帯 ¥120〜¥1,220。¥12,000 までの高額帯はジェム SKU）
- 成長パック（城 Lv 連動）、資源パック（不足連動）、加速パック、英雄欠片パック、復讐パック、ランキング逆転パック、復帰パック。
- 月パス ¥610（30 日: 毎日ジェム 100 + 60 分加速。2 本目ビルダーは含まない）。
- 成長ファンド ¥1,220（城 Lv 到達ごとにジェム返還。「元が取れる」演出）。
- ピギーバンク（行動でジェム蓄積、¥610 で開封。満杯で点滅）。
- ラッキーホイール（1 日 1 回無料、追加 ¥120 or ジェム 100。ハズレ少なめ、SSR 欠片が「惜しい」位置に止まる演出）。
- デイリーディール（毎日 3 枚、うち 1 枚は「99% OFF」で ¥120）。

## 3. オファーエンジン（`core.shop.OfferEngine`）
入力: `GameState` + `GameEvent` + 現在時刻。出力: 表示すべき `Offer`（SKU、文言 ID、残り時間、残数、トリガー種）のキュー。

| トリガー | オファー | 演出 |
| --- | --- | --- |
| 起動（1 日 1 回） | 本日限定パック | 全画面ポップ、発火から 24 時間のカウントダウン |
| 城 Lv アップ | 「城 Lv{n} 達成記念」 | 48h 限定、Lv に比例して内容が豪華に |
| 資源不足（建設/研究ボタン押下時） | 不足分 **ちょうど** 入ったパック | 不足量から動的生成。「あと {n} 石で建設可能！」 |
| ジェム不足（召喚/スキップ押下時） | 端数ぴったり SKU | 「あと {n} ジェム → ¥160 で解決」 |
| 敗北（襲撃） | 復讐パック | 資源 + 加速 + ジェム |
| 長時間タイマー開始（> 8h） | 加速バンドル | 「今なら残り時間を一瞬で」 |
| 購入直後 | 連鎖 Tier 解放 | 「Tier2 パックが解放されました！」 |
| イベント集計（2〜4 位） | ランキング逆転パック | 「1 位との差はあと {n} pt」 |
| 同盟社会的証明 | ジョニー等の「購入」通知 | チャット + 同盟ギフト箱（開けると小報酬） |
| 退出直前（戻る→タイトル確認） | 「待って！」 | 1 日 1 回、閉じる × は 2 秒遅延 |
| VIP 昇格間近 | 「あと {n} pt で VIP{v}」 | |
| 復帰（48h 以上不在） | 復帰パック | |
| ピギーバンク満杯 | 開封促し | バッジ点滅 |

制御:
- 頻度設定: `低 / 標準 / 量産型（既定）`。クールダウン（同 SKU 再表示まで 30 分〜）、連鎖は最大 3 連続、1 セッション上限（量産型: 無制限、標準: 5、低: 2）。
- 偽カウントダウン: 期限切れ後、同内容が別名で「復活！」（量産型のみ）。
- 残数: 「本日残り {n} 個」は日次リセット。
- 全オファーは `offers.json` でデータ化。トリガー条件は小さな DSL（`{"when":"castleUp","minLv":5}`）で表現。

## 4. ダークパターン・カタログ（実装する演出）
| パターン | 実装 |
| --- | --- |
| 偽希少性 | 残数表示、カウントダウン、「復活」 |
| アンカリング | 取り消し線定価、「価値 ¥24,800 相当」「95% OFF」 |
| バッジ | 「おすすめ」「人気 No.1」「最もお得」 |
| 確認優位 UI | 購入ボタンは大きく点滅、閉じる × は小さく薄く 2 秒後に出現 |
| 換算不明化 | SKU ごとにジェム単価が違う。ジェム→円の表示なし |
| 端数設計 | 召喚 300 ジェムに対し報酬は 250 刻み等、常に少し足りない |
| サンクコスト | 成長ファンド、ピギーバンク、月パス残日数 |
| 損失回避 | 「このまま閉じると特典消失」「初回 2 倍はあなただけ」 |
| 社会的証明 | 同盟メンバーの購入通知、ギフト箱、ランキング |
| 連鎖 | 購入で次 Tier 解放、「あと 1 回でステップアップ報酬」 |
| 強制中断 | タイマー完了直後にオファー、ログイン直後に 3 連ポップ |
| 復帰・初回限定 | 初回 2 倍、復帰パック |

## 5. 擬似決済フロー（`app` の `FakeBillingSheet`）
```
[価格ボタン] タップ（触覚フィードバック）
 → ボトムシート「お支払い」
    商品名 / 価格 / お支払い方法「•••• 4242」/ [1 タップで購入]（ロゴ無し、汎用デザイン）
 → 「処理中…」スピナー 1.2〜2.8 秒（10% で 4〜6 秒「確認しています…」）
 → 2% で「エラー: もう一度お試しください」→ 再試行で必ず成功（リアル感）
 → 「購入が完了しました ✓」チェックアニメ + 紙吹雪 + 効果音（任意）+ 注文番号 ORD-XXXX-XXXX（自前形式）
 → アイテムがインベントリへ飛ぶアニメ、ジェム数値カウントアップ
 → メールボックスに「レシート」
 → 連鎖オファー（該当時）
```
- 「処理中」の間はキャンセル不可（量産型感）。
- レシート本文の「（擬似・実支払い ¥0）」表記は設定で ON/OFF。既定 OFF（没入優先）。
- `FakeBillingSheet` は `core.shop.FakeLedger.record(...)` を呼び、`GameState` に報酬を付与するイベントを発行する。実通信なし。

## 6. 擬似課金台帳（`core.shop.FakeLedger`）
- 記録: `{epochSec, sku, priceYen, trigger, context}`。
- 設定 → 「課金履歴（擬似）」: 総額、月別、トリガー別、SKU 別、「実際の支払い: ¥0」。
- 既定で非表示。表示には「見る」1 ステップ確認。これはユーザー自身の振り返り用で、ゲームからは一切参照しない。
- エクスポート（JSON 共有）。

## 7. VIP（`core.shop.VipCalculator`）
- 擬似ジェム購入 ¥1 = 1 VIP pt、デイリーログインで 50〜300 pt（連続日数で増）。
- VIP Lv 表（`vip.json`）: 必要 pt、特典（建設キュー、採集 +%、デイリーチェスト内容、ジェムスキップ割引、オフライン上限）。
- 「VIP {n} 到達！」演出 + 同盟チャットに自動告知（AI メンバーが祝う）。

## 8. 設定項目
- オファー頻度（低/標準/量産型）
- 擬似決済演出（処理時間の長短、エラー演出 ON/OFF）
- レシートの「擬似」表記
- 台帳の表示
- 「本物の課金への誘導は存在しません」注意書き（設定画面最下部に常時）

## 9. 実装との同期メモ（M8 T8.3）
- 初回 2 倍は、全 6 ジェム SKU の基本ジェム分に適用する（ボーナス分は対象外）。
- トリガーの DSL の種類: login / castleUp / longTimer / defeated / rankingNear / comeback / vipNear / exitIntent / afterPurchase / piggyFull / secondBuilder。資源不足とジェム不足のオファーは DSL ではなくコードで動的に生成する（不足ちょうど、最小の SKU）。
- 2 本目ビルダーは `pack_builder`（期限制）か VIP6 で得る。
