# Crownfall 実機スモークチェックリスト（15〜20 分）

実機（Android 8.0 以上、通知確認のため Android 13 以上が望ましい）で、全画面を一巡して「落ちない・進む・戻る」を確かめる手順です。
各行の「期待」と違えば ✗ を付け、画面・操作・端末名をメモして Debugger に渡してください。文言は `app/src/main/res/values/strings.xml` に合わせています。

## 0. 準備（1 分）
- [ ] CI の artifact から APK を入手する。`crownfall-release-apk`（Secrets が無い実行では `crownfall-release-debugsigned.apk`、あれば `crownfall-release.apk`）。`crownfall-debug-apk` でも同じ手順で確認できる。
- [ ] 以前のビルドと署名が違うと上書きインストールできない。その場合はアンインストールしてから入れる（セーブは消える）。
- [ ] 期待: インストールでき、アプリ名は「Crownfall」。インストール時に課金や不要な権限の確認が出ない（通知のみ）。

## 1. 新規ゲームとチュートリアル（2 分）
- [ ] 起動 → タイトル。初回は「続きから」が無く「新規ゲーム」がある。
- [ ] 「新規ゲーム」→ 名前を空にして進む → 期待: 「名前を入力してください」。名前を入れ、「初期英雄を選んでください」で 1 体選んで開始。
- [ ] 城内で「空き地をタップして建物を建てましょう」→ 空き地 → 「建設する」→ 上のタイマーをタップして加速アイテムを使う（3 ステップ）。期待: 各ステップで次の案内に進み、最後に建物が完成。
- [ ] 別の新規ゲームではチュートリアルの「スキップ」で抜けられる。

## 2. 城内・建設・研究（3 分）
- [ ] 資源（食料・木材・石材・金貨）が時間と共に増える。倉庫が満杯のとき「○○の倉庫が満杯です」。
- [ ] 領主城を Lv5 まで上げる（加速アイテム・ジェムを使ってよい）。期待: 建物の詳細に必要資源・不足分（「あと ○○」）・前提（「○○ Lv n が必要」）が出て、足りないと実行できない。レベルアップでメッセージ「おめでとうございます！…」。
- [ ] ビルダー 2 本目（「建設 2」）が使える状態でも、キューが埋まると「建設キューが埋まっています」。
- [ ] 研究: 「研究」画面で枝（軍事など）のノードを 1 つ研究 → 完了通知「研究が完了しました！」と効果（例: 建設速度 +n%）が反映。
- [ ] 兵舎: 兵種を選んで数を決め「訓練する」→ 期待: 資源が減り、完了時「訓練が完了しました！」。維持費（食料 /時）が表示される。
- [ ] 酒場を建て、プレミアム召喚 → 英雄が増え「NEW!」。英雄画面でスキルを上げられる。

## 3. マップ（3 分）
- [ ] 下部ナビ「マップ」→ 自城の周りに資源地・野蛮人・砦。ドラッグで移動、タイルのタップで詳細（「城から n マス」）。
- [ ] 資源地 →「採集」→ 編成で兵を選んで出撃。期待: 行軍一覧に表示され、帰還後に資源が増えて「部隊が帰還しました」。
- [ ] 野蛮人 →「攻撃」→ 結果がメール（戦闘タブ）に届く。勝ち負けどちらでも落ちない。
- [ ] 「偵察」→ メール（偵察タブ）に結果。
- [ ] 砦などの「ラリー」を開始 → 集結待ち → 完了。
- [ ] 英雄が出撃中のとき、同じ英雄を別の行軍に選べない（「その英雄は出撃中です」）。

## 4. 同盟・チャット（2 分）
- [ ] 下部ナビ「同盟」→ タブ: メンバー / ヘルプ / 要請・ラリー / テック・ショップ / ギフト。
- [ ] ヘルプ: 自分のタイマーに「ヘルプ依頼」→ 数十秒〜数分でメンバーがヘルプ（「○○がヘルプしてくれました！」）、タイマーが縮む。「全部ヘルプ」も使える。
- [ ] 同盟テック: 寄付できる（上限あり）。同盟ショップ: ポイントで購入。ギフト: 「開ける」。
- [ ] チャット（城内メニューまたは同盟画面）: 同盟タブで発言 →「○○が入力中…」→ 返信。ワールドは読み取り専用。メンバーを選んで DM。
- [ ] 機内モード・API キー無しでも返信が来る（Scripted）。

## 5. ショップ（擬似課金）とレシート（2 分）
- [ ] 下部ナビ「ショップ」→ タブ: おすすめ / ジェム / パック / デイリーディール / VIP / 月パス・ファンド。
- [ ] ジェムの商品を購入 → 擬似の決済演出 → 完了。期待: ジェムが増える。メール「レシート」に注文番号（ORD-XXXX-XXXX）、金額、「（擬似・実支払い ¥0）」。同じ注文番号は重複しない。
- [ ] 画面のどこにも実在の決済サービス名・Google Play の購入ダイアログは出ない（出たら重大）。
- [ ] 購入済みの限定オファーは再購入できない。期限切れのオファーは消える。

## 6. クエスト・イベント（2 分）
- [ ] クエスト: メイン / デイリー / 同盟 / 実績。達成した項目の「受け取る」→ 「受け取り済み」。2 回は受け取れない。デイリーのポイントで宝箱。
- [ ] イベント（開催中のバナー「開催中: ○○」）: 残り時間・自分のスコア・順位・順位報酬が出る。採集や討伐でスコアが増える。

## 7. 通知（2 分）
- [ ] 初回、通知の許可を求められる → 許可。
- [ ] 設定 → 通知: 建築等 / 限定オファー / 同盟 / 襲撃を個別にオン・オフできる。権限が無いと案内（「通知の権限がありません」）と端末設定へのリンク。
- [ ] 長めの建設を開始 → ホームボタンでアプリを閉じ、完了時刻まで待つ（加速アイテムで残りを数分にしておく）。期待: 「建物の強化が完了しました」の通知。タップでアプリに戻る。
- [ ] 通知を「建築等」オフにして同じことをすると通知されない。

## 8. セーブと復帰（2 分）
- [ ] 建設・訓練・行軍を走らせた状態でアプリを完全終了（タスク一覧から消す）→ 数分後に起動 →「続きから」。期待: 進行が不在の間も進んでいて、不在中のまとめ「あなたが不在の間に…」（完了した建設など）が出る。
- [ ] 端末の時刻を戻さない（時計を戻すと進まなくなるのは仕様）。
- [ ] 24 時間を超える不在では「オフライン上限（24 時間）に達しました」。長期放置後の起動で落ちない。
- [ ] 新規ゲームで上書きする前に「新規ゲームを開始しますか？／現在のセーブデータは上書きされます。」の確認が出る。

## 9. 設定（2 分）
- [ ] AI チャット: Gemini / OpenAI 互換のオン・オフと順序、API キー欄（保存後は表示されない）、呼び出し予算、「AI かと聞かれたら認める」、直近 24 時間の呼び出し回数。キー無しでも Scripted で動く。不正な URL（http で外部ホスト）は「http は LAN / localhost / *.local のみ使えます」で拒否される。
- [ ] ショップ（擬似課金）: 「オファーの頻度」を 低 / 標準 / 量産型 に切り替えられ、頻度が変わる（低では弾が出にくい）。「決済の処理時間を長めにする」「まれにエラー演出（再試行で必ず成功）」。
- [ ] 課金履歴（擬似）:「見る」→ 確認ダイアログ（実際の支払いではありません）→ 総額・件数・「実際の支払い: ¥0」・月別/トリガー別/商品別・JSON 共有。
- [ ] 「本物の課金への誘導は存在しません…」の文言がある。

## 10. 異常系（任意・1 分）
- [ ] 画面回転・ホーム→復帰・他アプリとの切り替えで状態が壊れない。
- [ ] 機内モードで全画面が動く（AI だけ Scripted にフォールバック）。
- [ ] 戻るボタンで各画面から城内に戻れ、城内の戻るでアプリが終了する。

## 11. M9: オンデバイス LLM と通知の強化（5〜8 分・M9 を含むビルドのとき）
文言と画面の場所は M9 の実装に合わせて確認する（本章は機能単位）。通知の確認は端末の通知権限を許可した状態で行う。

### 11-1 モデルファイルとオンデバイス AI
- [ ] 設定 → AI チャットで OnDevice のモデルを読み込む。**ファイル選択**（端末内のモデルファイル）と **URL ダウンロード**の両方。期待: 進捗が出て、完了すると使用可能になる。不正なファイルは失敗理由が出て、他のプロバイダーの動作は変わらない。
- [ ] URL ダウンロードの途中で **中断**（機内モード、アプリ終了）→ 再開。期待: 最初からではなく続きから再開、または再開できない理由が出る。破損した部分ファイルが残ったまま「使用可能」にならない。
- [ ] **端末要件の表示**: メモリ・空き容量・対応状況が出る。要件を満たさない端末では読み込みを促さず、理由を表示（Scripted に自動フォールバック）。
- [ ] 機内モードでチャット（同盟・DM）→ **OnDevice が発話**する（Scripted の定型文ではない）。順序設定で OnDevice を最後にすると Scripted/他が先に使われる。
- [ ] **背景に回したときのメモリ解放**: チャットで OnDevice を使った後にホームへ戻り、数分後に端末のメモリ使用量（設定 → アプリ）が下がる。復帰後の最初の発話が成功し、落ちない。
- [ ] 発話が遅い／失敗するときも画面が固まらず、Scripted に切り替わる。

### 11-2 襲撃の通知（段階・強度）
- [ ] 見張り塔のレベルを変えて、襲撃が **段階（偵察された → 進軍中 → 1 時間前 → 15 分前 → 開始 → 結果）**ごとに通知される。期待: 見張り塔の Lv が低いほど見える段階が少ない。
- [ ] **ロック画面**に通知が出る（内容が伏せられず読める／設定どおり）。**バイブ**は強度に応じて鳴る。
- [ ] 設定の **強度 LOW / STANDARD / MASS（既定 MASS）**を切り替え、通知の数・頻度が段階ごとに違う。**1 時間あたりの上限**を超えない（超えた分は「まとめ」通知になる。襲撃は上限の対象外で必ず届く）。
- [ ] **おやすみ時間**（既定 OFF）: 時間帯を設定し、建築完了や限定オファーなど襲撃以外の通知がその時間に当たるようにする。期待: その間は鳴らず（まとめて）おやすみ明けに届く。**襲撃の通知は例外でおやすみ中も鳴る**。解除すれば通常どおり。
- [ ] **exact alarm**（Android 13 以降は USE_EXACT_ALARM で自動、12 は「正確なアラーム」の許可が必要）: 許可あり → 時刻どおりに通知。許可なし（12 で拒否）→ 案内が出て、通知は多少遅れても出る（落ちない、消えない）。
- [ ] **再起動後の通知の復元**: 予約がある状態で端末を再起動 → アプリを開かなくても、予告時刻に通知が出る。

- [ ] **復帰の催促**（4 時間 / 24 時間 / 72 時間 / 7 日）: アプリを閉じて待つと、ゲーム外の通知として届く。再び開くと古い催促は消える。

### 11-3 不在中の襲撃
- [ ] アプリを閉じたまま襲撃の到着時刻を過ぎ、通知からアプリを開く。期待: 最前面に **「不在中に襲撃されました！」** のポップアップ（結果: 撃退／敗北、奪われた資源）。閉じるとメールにも同じ結果が残る。
- [ ] 24 時間を超えて閉じていた場合、**オフライン上限を超えた分の襲撃を予告・実行しない**（上限内の結果だけが出る）。
- [ ] ポップアップの結果と、同じ時刻までアプリを開いて遊んだ場合の結果が **一致**する（開いていても閉じていても同じ）。

## 結果の渡し方
✗ の項目は「章番号・操作・期待と実際・端末名・Android バージョン・APK の artifact 名と CI run 番号」を書いて Debugger へ。
クラッシュは、可能なら `adb logcat -b crash` の出力も添付する。
